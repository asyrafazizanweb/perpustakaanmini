1. Sambungan pangkalan data

Masukkan URL projek Supabase dan kunci anon/publishable projek anda. Jangan masukkan service_role key. Maklumat sambungan disimpan pada pelayar ini sahaja.

Sambung peranti lain tanpa menaip kunci

Pada peranti yang sudah berjaya disambungkan, salin pautan atau kod sambungan dan hantar kepada diri sendiri (contohnya melalui WhatsApp/e-mel). Buka pautan itu di telefon, atau tampal kod di bawah. Kata laluan akaun tetap diperlukan untuk log masuk.

Persediaan Supabase Storage untuk gambar kulit buku (sekali sahaja)

Jalankan SQL ini dalam Supabase → SQL Editor. Ia mencipta bucket peribadi covers dan membenarkan setiap pengguna mengakses folder miliknya sahaja. Jika langkah ini belum dibuat, gambar kulit tetap disegerakkan (dalam bentuk mampat) bersama rekod.

insert into storage.buckets (id, name, public)
values ('covers', 'covers', false)
on conflict (id) do nothing;

create policy "covers_select_own" on storage.objects for select to authenticated
  using (bucket_id = 'covers' and (storage.foldername(name))[1] = auth.uid()::text);
create policy "covers_insert_own" on storage.objects for insert to authenticated
  with check (bucket_id = 'covers' and (storage.foldername(name))[1] = auth.uid()::text);
create policy "covers_update_own" on storage.objects for update to authenticated
  using (bucket_id = 'covers' and (storage.foldername(name))[1] = auth.uid()::text)
  with check (bucket_id = 'covers' and (storage.foldername(name))[1] = auth.uid()::text);
create policy "covers_delete_own" on storage.objects for delete to authenticated
  using (bucket_id = 'covers' and (storage.foldername(name))[1] = auth.uid()::text);

3. Penyegerakan

Penyegerakan kini digabungkan per rekod: setiap buku, pinjaman dan kategori mempunyai masa kemaskini sendiri, jadi perubahan berbeza dari telefon dan komputer akan digabungkan. Hanya jika rekod yang sama diubah pada dua peranti, versi yang paling baharu akan dikekalkan. Rekod yang dipadam turut dipadam pada peranti lain. Kali pertama peranti ini disambungkan dan kedua-dua tempat ada data, anda akan diminta memilih sama ada mahu menggabungkan data atau menggunakan data awan.

Perubahan dihantar secara automatik kira-kira 1.2 saat selepas simpan, dan data awan disemak semula apabila anda kembali ke tab ini atau setiap 2 minit. Dua butang "Ganti" hanya untuk kes khas; sandaran tempatan dibuat secara automatik sebelum data peranti ini diganti.
